## 1. 面对面单人和多人组选择

- [x] 参考剧情 APP 的选择方式，分别展示单人角色与已保存的多人组。
- [x] 多人组可创建、自动按成员命名、保存、选择和删除；再次进入时恢复该组的对话记录与上次地点。
- [x] 单人与不同多人组各自保存记录，保留已有记录、主线、分线及独立见面的正确归属。
- [x] 切换要编辑的角色，不改变当前多人组成员、当前对话或共同地点。

## 2. 多人面对面地点与立绘修复

### 已报告的问题

选择多个角色后，地点被限制为第一个角色的地点，无法正常更换。剧情推进到第二个角色发言时，其立绘未正常显示。

### 目标行为

- [x] 多人地点选择包含组内角色的可用地点及通用地点，不受首位角色限制。
- [x] 同名地点标明归属，保存时准确区分具体地点，避免只凭“客厅”等名字错误匹配。
- [x] 选定地点作为本次见面的共同地点；切换发言人时保持地点和背景一致，实际换场后再更新。
- [x] 地图进入、直接开启见面、继续旧对话都能恢复正确的地点关联及原有氛围音行为。
- [x] 当前发言角色的台词、语音与立绘同步切换，处理异步加载和多人顺序播放，避免 A 的画面配 B 的台词。
- [x] 优先使用该角色在当前地点匹配的立绘，缺少匹配时使用该角色自己的默认立绘或明确的头像/缺素材提示，不错用其他角色素材。
- [x] 验证各角色的情绪立绘、拖动位置与缩放互不串用；切换已有素材不额外触发生图。

## 3. 面对面独立参数与设置预设

每个单人角色、每个多人组分别保存参数；仅同一多人组内部共用该组参数。单人保留原有完整设置页；多人组分为“本组参数”和“成员素材与语音”，点选角色进入该角色的设置。

- [x] 增加设置预设的保存、命名、选择和应用，用于一键套用一整套设置数值。
- [x] 预设范围从“生成 CG 图（新画面）”区域开始，覆盖其下的生成要求与对话外观设置。
- [x] 同组参数不因发言角色切换而交替生效；修改某个角色或多人组，不改变其他角色和组的参数。
- [x] 设置对象可以独立切换，不改变当前见面对象、地点与对话。保存按钮放在预设名称框旁，应用按钮放在预设列表旁，均为小按钮。
- [x] 应用预设与编辑某位角色的素材/语音分清作用范围，保留每个角色自己的素材与音色绑定。
- [x] 保存后重开、切换多人组以及备份恢复后，设置和预设仍正确生效。

| 设置区域 | 预设覆盖内容 |
| --- | --- |
| CG 设置 | 开关、生图间隔、自动展示轮数、跳过 NSFW、CG 额外要求、人物参考来源等设置值 |
| 生成要求 | 生成格式、对话符号、额外提示词、回复长度与自定义字数、语音开关、记忆开关 |
| 对话外观 | 气泡颜色、不透明度、文字颜色、字号 |

角色参考图按实际出镜角色的绑定读取；默认 NPC 性别、立绘布局、场景素材与音色归各角色。预设只复制参数数值，应用时只更新当前设置对象。

## 5. 反查岗“我的收藏”：轻量展示与简化互动

在“我的手机”反查岗中增加“我的收藏”APP，读取同一份真实收藏。外部收藏 APP 保持完整管理界面，反查岗使用轻量查看界面。

### 展示方式

- [x] 进入后直接显示最近的、允许查看的收藏，不强制逐层选择“来源 → 角色/组 → 列表”。
- [x] 卡片只展示来源、相关角色/组、图片缩略图或约两行文字摘要，点击后展开完整内容。
- [x] 顶部保留“全部/图片/文字”等简洁入口；角色、组、来源和标签筛选放入可选筛选按钮。
- [x] 图片列表使用三列九宫格，支持点击放大；文字和整段对话沿用真实收藏卡片与展开内容。
- [x] 内容限定为当前用户身份、账号和允许该角色查看的范围，不将其他账号、身份或未授权内容混入。
- [x] 外部真实收藏的变化能反映到该入口，不生成虚构收藏。

### 模拟过程

- [x] 默认流程为“进入收藏 → 看当前一屏 → 挑少量条目打开 → 边看边反应 → 返回”；必要时可继续翻阅或筛选。
- [x] 通常先查看少量条目，例如 2～3 条，并设置查看/翻页上限，避免长收藏无限浏览。
- [x] 保留简单的点击、展开、停留、返回操作，减少无意义的层层筛选、长距离滚动和重复模型调用。
- [x] 文字依据实际展示的内容反应；图片页或放大图片按实际可见区域截图，交给支持识图的模型。
- [x] 模型仅接收本次实际可见的内容；没打开的详情、没展开的聊天不能描述成已经完整看过。
- [x] 查看记录区分缩略图浏览、打开详情和展开内容，沿用已有查岗记录、回放与记忆流程。
- [x] 识图截图按临时请求数据管理并及时释放；回放沿用现有媒体去重和容量控制，避免另存多套完整图片。
- [x] 识图不可用时给出真实提示；不根据截图虚构语音或视频中未被实际获取的内容。

## 本轮实现边界与验证命令

- 反查岗默认仅看当前一屏，最多打开3条；至多再切换一次图片/文字分类或翻一页；每条至多再展开/切换一条内容。每次读取均发生在实际页面动作之后。
- 收藏入口只读取当前账号、身份及允许角色名单内的数据。多人收藏要求所有成员都在名单内；可在反查岗设置中隐藏或锁定“我的收藏”。
- 成品、收藏入口共用原图引用；删除来源会保留仍被收藏引用的媒体。取消收藏不主动清理其他来源仍可能使用的文件。本轮不批量删除旧版历史缓存，回放继续使用既有去重媒体快照策略。
- 多人组、各角色与组的参数、预设保存在已有面对面配置键中，随“创作”模块备份；独立收藏 ZIP 会嵌入所需媒体，恢复不依赖原来源模块。没有新增相册数据库或备份选项。
