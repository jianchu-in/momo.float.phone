# 内置详细场所模板

地图底部「详细场所模板」，或地点介绍里的「套用场所模板」，可以直接加入一张完整底图和对应地点。模板使用静态资源，不调用用户配置的文字、生图或识图模型。

| 模板 | 一张图内的主要分区 | 点位数 |
| --- | --- | --- |
| 经典商场 | 服装、美食、电玩、电影院、甜品、咖啡、服务、洗手间 | 10 |
| 经典游乐园 | 过山车、摩天轮、旋转木马、碰碰车、游船、花园、小食、纪念品 | 11 |
| 通用海边 | 海岸、沙滩、栈桥、灯塔、咖啡、海鲜、排球、更衣淋浴 | 12 |
| 通用公寓 | 主卧、次卧、浴室、阳台、厨房、客厅、餐厅、玄关、走廊 | 9 |

商场使用一张综合分区图，不再分为六层图片。坐标与地点介绍的唯一来源是 `lib/facing-map-templates.ts`，坐标按原图宽高的百分比记录，安装时转换为地图逻辑坐标。四张原图位于 `public/facing-map-templates/*.png`；`previews/*.webp` 只用于轻量预览。安装和下载都使用未改写的原始 PNG。

模板可以用于当前空白地图、已有地点的空白内部地图，或新增一个地点。安装使用新地点 ID，并把原图复制到现有的本地媒体存储中，便于沿用备份、下载和编辑。已有内容不会被覆盖；中途失败会清理尚未使用的图片副本。

地点介绍浮在地图上。缩放、拖动位置按地图保存于当前界面内，打开详情或改变编辑状态不会触发重新适配；「全图」仍可主动适配。前往路线始终是当前位置到目的地的直线，支持虚线、实线与头像移动。跨地图时逐段衔接入口，没有配置入口时自动使用地图内已有位置，无需手动画路。旧备份中的道路数据保留兼容，但不再参与展示、边界计算和前往路线。

## 图块管理与看图

「图块与扩展」可以选择已生成或上传的图块，修改名称、独立描述、X/Y 坐标、地图宽高和层级；支持锁定比例、按面积放大、贴到其他图块四侧及直接在地图中拖动。地点通过图块 ID 关联；旧数据在首次修改时按可见图块位置推断归属。移动和缩放只作用于关联地点，地点 ID 和内部地图坐标保持稳定。删除默认只移除图片，另可勾选一并删除关联地点及其内部地图。

「润色描述 / 重新生图」会载入所选图块的描述和现有地点。文字润色保留地点 ID，可以单独保存文字与区域；重生可参考原图、修改图片像素比例和地图逻辑面积。生成结果先预览，确认保存时才替换原图块。取消或失败不会替换已保存图块。

地图中央以当前地图的虚化图像作背景。「全图」下方新增「铺满」，按地图图片整体边界覆盖中央区域，支持上下左右拖动与放大，缩小和拖动均受边界限制；「普通」切回原有视图。打开地点介绍、编辑标记、重生替换图片不重置已有视图。

## 导入导出

- 「导入 / 导出」支持整个大地图 JSON，包含所有地图原图、图块尺寸和位置、地点说明、地图入口与多级内部地图。
- 地点介绍中的「导出此地点」只打包该地点及其内部地图，可在「导入场所模板」中加入自定义模板列表，再应用到空白地图、现有地点的空白内部地图或新地点。
- 整图文件也可选择作为模板导入。自定义模板支持再次导出和从模板列表移除，移除模板不影响已经应用的地图。
- 导入会重建地图、地点、图块和媒体 ID，保留层级关系；完整校验结构和图片，避免覆盖现有地图。取消或失败会清理尚未提交的图片。
- 地图布局包不携带动向、私聊邀请、见面记录或外部账号绑定。这些记录继续保留在原设备的原地图中。

## 本次验证

TypeScript 检查通过。使用实际四张图片验证模板安装与原图逐字节保留；整图与单地点导出导入、ID 重建、旧图块关联推断、图块移动缩放、保留/删除内部地图、取消与无效文件、防覆盖均通过。浏览器验证打开详情不变缩放、铺满最小缩放与拖动边界、图块表单和直接拖动、文字润色、携带原图和指定尺寸的重生、预览后替换及内部地图保留。文字和生图调用采用模拟接口验证请求与保存流程，实际出图质量取决于用户配置的模型。
