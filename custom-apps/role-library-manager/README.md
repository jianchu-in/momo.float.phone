# 角色库管理 (Role Library Manager) · 0.1.0

**独立的、小手机可安装的私人自定义 APP**。它不是小手机内置页面，也不需要改动宿主源代码。未发布到应用市场，仅供私人导入和测试。

## 安装

1. 打开“小手机 → 应用市场 → 创作 → 导入整包 → 本机测试”。
2. 选择提供的 **角色库管理-v0.1.0.zip**，它包含 `manifest.json`、`index.html`、`icon.png`，不要选择源码 ZIP。
3. 在“角色库管理”中导入酒馆 `PNG`（带 `chara`、`ccv3` PNG 元数据）或角色卡 `JSON`，可以多选。
4. 进入角色操作台查看人物设定、原始 JSON、默认及备用开场、世界书及扩展正则；需要小手机数据关联时才点击“同步到剧情”。

## 宿主依赖

角色资料写入、开场集合与分线、正则与剧情专属绑定等功能需要宿主的 **PR #29 剧情与自定义 APP 交互接口升级**（目前未合并）。

- 在原版 `main` 宿主中，角色库可通过私有 `db` API 存储和预览角色卡，但新版写入与剧情功能不可使用。
- 在部署的 PR #29 预览宿主中，安装后可验证角色同步、开场、分线以及绑定。
- 这套 APP 不触碰线上聊天或聊天记录，导入的开场只在用户明确操作后成为线下长文剧情开场。

## 数据安全

- 导入时只保存到 APP 私有数据库。角色卡 `data`、`extensions`、任意不认识的 JSON 字段完整保留；编辑已知字段不会把未知字段扔掉。
- PNG 源文件保存到 APP 私有媒体存储（大小限制约 25MB）；如保存失败，本次文件不会被标记成功。
- 打开“原始数据”可将保留的数据导出为 JSON；PNG 可单独导出原始图片。*修改过角色文字后，原始 PNG 仍然是导入时的版本，不会将新数据重新写入 PNG 元数据。*
- “设置与备份”提供 JSON 备份，**不包含 PNG 图像字节**，PNG 须逐个单独导出，避免误以为是完整的媒体备份。
- 角色卡文件本身不一定带历史消息；目前仅对角色卡执行解析，没有导入历史聊天文件。
- 只在点击“同步到剧情”后按原始文本组合设定并写入宿主角色，世界书与正则分组仅绑定剧情。
- 当前版本同步世界书与正则会将其转换为宿主支持的字段，少数 SillyTavern 专有扩展字段不会应用到宿主规则引擎中，但原始字段仍在本 APP 中。

## 文件结构

- `manifest.json`: APP 权限与入口。
- `index.html`: 离线自包含入口（整合 `src/style.css`、`src/importer.js` 和 `src/app.js`），不依赖外部 CDN。
- `icon.png`: APP 图标。
- `src/`: 可编辑源码。
- `tests/importer.test.cjs`: 导入器 Node 单元测试。

已用 Node.js 测试 V1/V2/V3 JSON、PNG tEXt 与 zTXt、嵌套扩展字段保留、无效 PNG 拒绝。需要在实际安装的 PR #29 宿主预览中测试 `AiPhone` 权限、媒体存储与线下剧情同步；没有宣称完成这部分真机测试。
